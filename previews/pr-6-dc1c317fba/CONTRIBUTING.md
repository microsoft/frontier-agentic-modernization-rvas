# Contributing

Contributions and suggestions are welcome. Most contributions require a
Contributor License Agreement (CLA) confirming that you have the right to grant
us permission to use your contribution and that you grant it. For details, visit
https://cla.microsoft.com.

When you submit a pull request, the CLA bot checks whether you need an agreement
and adds a label or comment with instructions. Follow those instructions.
You only need to do this once across all repositories using our CLA.

This project has adopted the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).
For more information see the [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/)
or contact [opencode@microsoft.com](mailto:opencode@microsoft.com) with any additional questions or comments.
