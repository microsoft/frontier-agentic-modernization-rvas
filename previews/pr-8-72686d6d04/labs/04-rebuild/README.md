# Rearchitect and rebuild

Rebuild a complete application with the architecture-first plugin: discovery and planning, package review, a chosen implementation workflow, app review, frontend refinement, security fixes and an Azure deployment. Java or .NET knowledge is not required.

## Challenges

| # | Challenge | Capability |
|---|-----------|------------|
| [00](challenges/00-prepare-your-application.md) | Prepare Your Application | App boundary, brief and decision owners |
| [01](challenges/01-discovery-and-planning.md) | Discovery and Planning | Analysis, decisions and the nine-artifact package |
| [02](challenges/02-review-the-package.md) | Review the Package | Evidence checks and corrections |
| [03](challenges/03-choose-the-workflow.md) | Choose the Workflow | Direct, Matt Pocock or Spec Kit delivery |
| [04](challenges/04-rebuild-the-app.md) | Rebuild the App | Implementation of the complete app |
| [05](challenges/05-review-and-fix-the-app.md) | Review and Fix the App | `/review` and missing behavior |
| [06](challenges/06-refine-the-frontend.md) | Refine the Frontend | Scoped UI improvements with Impeccable |
| [07](challenges/07-security-review-and-fixes.md) | Security Review and Fixes | `/security-review` and fixes |
| [08](challenges/08-run-and-deploy.md) | Run and Deploy | Validation and Azure deployment |

## Requirements

Follow the [setup and usage guide](setup.md) and the [supporting-skill profiles](supporting-skills.md). See the shared [prerequisites](../../README.md) for tools and access.

Challenge files hold per-challenge notes under **Hints and notes**. Pacing and stuck points are in [pacing and troubleshooting](pacing-and-troubleshooting.md); score your own evidence with the [self-check](self-check.md).
