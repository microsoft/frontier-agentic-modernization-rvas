Prerequisites

The tools below support the upgrade tracks. For architecture-first work, use the rebuild plugin setup; the Modernization CLI is not a rebuild prerequisite.

VS Code
Required for the GitHub Copilot Modernization extension workflow
Docker Desktop
Required by Dev Containers and for building container images
GitHub Copilot Modernization
VS Code extension + modernize CLI — install from the VS Code Marketplace
GitHub CLI (gh) v2.45.0+
Required by the modernization CLI — authenticate with gh auth login
Azure CLI + Terraform
Active Azure subscription with permissions for Container Apps, SQL, Service Bus, and Blob Storage
Install Modernization CLI bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/microsoft/modernize-cli/main/scripts/install.sh | sh
source ~/.bashrc
 
# Windows
winget install GitHub.Copilot.modernization.agent
 
# Authenticate and launch
gh auth login
modernize
Clone with Submodules bash
git clone --recurse-submodules \
https://github.com/<org>/<repo>.git
 
# Verify submodules are populated
git submodule status
✓ a3f8c... Student/Resources/java/PhotoAlbum-Java
✓ 9d2e1... Student/Resources/dotnet/dotnet-migration...
 
# Verify CLI is ready
modernize --version
modernize v1.x.x

Rearchitect / rebuild

Follow explicit prompts from discovery to Azure deployment. Review the package, choose direct, Matt Pocock, or Spec Kit delivery, then review, refine, and secure one slice. Allow two days for the route, not a whole-application rewrite. Discovery may favor a smaller refactor.

Not for mainframe modernization

This route is for modern and traditional non-mainframe application languages and architectures, such as .NET and Java web apps, APIs, and services. Do not use it for mainframe applications.
