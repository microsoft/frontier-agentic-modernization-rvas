# Rearchitect and rebuild

Rebuild a complete application with the architecture-first plugin: discovery and planning, package review, a chosen implementation workflow, app review, frontend refinement, security fixes and an Azure deployment. Java or .NET knowledge is not required.

## Modules

| # | Module | Duration | What you do |
|---|--------|----------|-------------|
| [00](challenges/00-prepare-your-application.md) | Prepare Your Application | 30 minutes | Set the app boundary, write the brief and name decision owners |
| [01](challenges/01-discovery-and-planning.md) | Discovery and Planning | 150 minutes | Run analysis, decisions and the nine-artifact package |
| [02](challenges/02-review-the-package.md) | Review the Package | 45 minutes | Check the package against evidence and correct it |
| [03](challenges/03-choose-the-workflow.md) | Choose the Workflow | 45 minutes | Pick direct, Matt Pocock or Spec Kit delivery |
| [04](challenges/04-rebuild-the-app.md) | Rebuild the App | 150 minutes | Implement the complete app |
| [05](challenges/05-review-and-fix-the-app.md) | Review and Fix the App | 60 minutes | Run `/review` and implement missing behavior |
| [06](challenges/06-refine-the-frontend.md) | Refine the Frontend | 60 minutes | Make scoped UI improvements with Impeccable |
| [07](challenges/07-security-review-and-fixes.md) | Security Review and Fixes | 45 minutes | Run `/security-review` and fix findings |
| [08](challenges/08-run-and-deploy.md) | Run and Deploy | 60 minutes | Validate locally and deploy to Azure |
