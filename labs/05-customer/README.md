# Customer application

Apply the Modernization CLI workflow from the .NET and Java labs to a real, customer-owned application. For substantial architecture or business-workflow change, use the [rebuild lab](../04-rebuild/README.md) instead.

## Modules

| # | Module | Capability |
|---|--------|------------|
| [00](challenges/00-upgrade-a-customer-app.md) | Upgrade a Customer Application | Select, assess, modernize and deploy a customer app |

Plan for about 480 minutes (one working day).

## Requirements

See the shared [prerequisites](../../README.md) and the [labs guide](../README.md) for Azure requirements. Requires access to the customer repository and a way to build it locally.

## Notes

The module covers application selection, readiness checks and troubleshooting. The [troubleshooting guide](../TROUBLESHOOTING.md) covers Terraform provider registration and network-policy blocks.
